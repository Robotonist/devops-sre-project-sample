# v0.2 UTM Bootstrap

## VM requirements

- UTM virtualization, not x86 emulation
- Ubuntu Server 26.04 LTS ARM64
- Shared Network
- 4 vCPU
- 8 GiB RAM
- 40 GiB virtual disk
- OpenSSH Server enabled during Ubuntu installation

## After first boot

On the Ubuntu guest:

```bash
uname -m
lsb_release -ds
ip -br addr
systemctl is-active ssh
```

Expected:

- `uname -m` -> `aarch64`
- Ubuntu release reports `26.04 LTS`
- one non-loopback address is visible
- SSH reports `active`

From the Mac:

```bash
ssh <admin-user>@<guest-ip>
```

Do not install application dependencies manually. Once SSH succeeds, Ansible owns the appliance configuration.
